# Guía de uso

`guia-de-uso-saludplus.html` es la guía interactiva para el usuario: cada pantalla del sistema con sus partes numeradas y un recorrido guiado por puesto (ingreso del personal, tótem, secretaría, consultorio, sala, cierre del día y dirección).

Para verla, descargue el archivo y ábralo con doble clic. Funciona sin internet y sin instalar nada.

Las capturas se tomaron de la rama `main` con los datos de demostración (`?reset=1`). Si cambia una pantalla, hay que volver a sacarlas.

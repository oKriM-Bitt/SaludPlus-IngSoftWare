# Guía de uso

`guia-de-uso-saludplus.html` es la guía interactiva para el usuario: cada pantalla del sistema con sus partes numeradas y un recorrido guiado por puesto (ingreso del personal, tótem, secretaría, consultorio, sala de espera y boxes, cierre del día y dirección). Son 43 pantallas, incluidas el llamado a box desde admisión y la pantalla de boxes de la TV de admisión.

Para verla, descargue el archivo y ábralo con doble clic. Funciona sin internet y sin instalar nada.

También viene con el programa: la app la sirve en `/guia-de-uso.html` (copia en `frontend/public/guia-de-uso.html`) y se abre desde el menú de usuario, en **Guía de uso**. Desde la app muestra solo las pantallas del rol que la abre (`?rol=`); abierta como archivo o por dirección, muestra todas. Si se actualiza la guía, hay que reemplazar los dos archivos.

Las capturas se tomaron con el logo nuevo y los datos de demostración (`?reset=1`). Si cambia una pantalla, hay que volver a sacarlas.
